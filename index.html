Meetspace help

Quick answers to help your meetings run smoothly.

How do I start or join?

Choose New meeting to start a room, or select Join with a code and enter the code from your host.

Where are my recordings?

Stop a recording to save it on this browser and download a copy. Open Recordings in the left menu to play it later on this device.

How do I add a meeting to my calendar?

Open My meetings and choose Add to calendar to download an invite file for your calendar app.

Why are Google or Microsoft sign-in buttons not connecting?

Those providers need OAuth credentials from their developer consoles. Add them to the local .env file and restart Meetspace.
